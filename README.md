# 🛒 বাজার দর (Bazar Dor)

বাজার দর হলো একটি ওয়েব অ্যাপ্লিকেশন, যার মাধ্যমে খুব সহজেই নিত্যপ্রয়োজনীয় জিনিসপত্রের বর্তমান বাজারমূল্য জানা যায়। এখানে ক্যাটাগরি অনুযায়ী প্রোডাক্ট ফিল্টার করা, দাম কমা-বাড়ার পরিমাণ দেখা এবং বিভিন্ন মার্কেটের তুলনামূলক দাম দেখা যায়।

## 🚀 Technologies Used
- **Next.js (App Router):** ফাস্ট পেজ নেভিগেশন ও সার্ভার সাইড রেন্ডারিং এর জন্য।
- **Tailwind CSS & HeroUI:** দ্রুত ও সুন্দর ইউজার ইন্টারফেস ডিজাইনের জন্য।
- **BetterAuth:** সুরক্ষিত এবং সহজ অথেনটিকেশন (লগ-ইন/রেজিস্ট্রেশন) সিস্টেমের জন্য।
- **TypeScript:** টাইপ সেফটি এবং ক্লিন কোড লেখার জন্য।
- **React Toastify:** সুন্দর ও রিয়েলটাইম নোটিফিকেশন দেখানোর জন্য।

## ✨ 5 Key Features
1. **Dynamic Price Ticker:** ওয়েবসাইটের উপরে চলমান টিকারে বিভিন্ন পণ্যের বর্তমান দাম দেখা যায়।
2. **Product Filtering & Sorting:** ক্যাটাগরি অনুযায়ী প্রোডাক্ট ফিল্টার করা এবং দাম বা বৃদ্ধির হার অনুযায়ী সর্ট (Sort) করার সুবিধা।
3. **Authentication:** BetterAuth দিয়ে ইমেইল-পাসওয়ার্ড এবং সোশ্যাল মিডিয়ার মাধ্যমে সহজেই অ্যাকাউন্ট তৈরি এবং লগইন করা যায়।
4. **Profile Management:** লগইন করা ইউজার নিজের প্রোফাইলে গিয়ে নাম আপডেট করতে পারবে।
5. **Responsive Design:** মোবাইল, ট্যাবলেট এবং ডেস্কটপ - সব ধরনের ডিভাইসেই খুব সুন্দরভাবে ওয়েবসাইটটি ব্যবহার করা যায়।
